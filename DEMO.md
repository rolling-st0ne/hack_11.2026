# Демонстрация за шесть минут

## Подготовка

Node.js ≥22.13. Из каталога `fotoprint` выполнить `CONTOUR_BI=off npm start`, открыть http://localhost:3000. Установка npm-пакетов не требуется. Для LAN используется адрес из `npm run address`; сервер должен быть доступен в той же сети.

Первый запуск создаёт `.data/auth/ACCESS.txt`. Заранее выдайте демонстратору записи `executive`, `maxim` и `analyst`; не публикуйте файл. Вход — логин и пароль. Для смены роли нажмите «Выйти» и войдите другим аккаунтом. Открытого переключателя ролей в локальном режиме нет.

Набор зафиксирован на дату генерации. Для свежих относительных периодов используйте новый демонстрационный каталог: `npm run seed`, затем `CONTOUR_FILES=/private/tmp/contour-demo/files CONTOUR_AUTH=/private/tmp/contour-demo/auth CONTOUR_BI=off npm start`. Это не сбрасывает старые рабочие решения. Пароли нового стенда находятся в указанном CONTOUR_AUTH/ACCESS.txt. При уже работающем экземпляре задайте свободные PORT/API_PORT.

## Сценарий

| Время | Действие | Что видно |
|---|---|---|
| 0:00–0:40 | Войти как executive, открыть «Дашборд» | План, факт, прогноз, цветовой статус обязательных KPI; русские подписи |
| 0:40–1:25 | Выбрать период, подразделение и продукт; открыть KPI и связанный заказ | Пересчёт среза, формула, источники и их время, причина отклонения |
| 1:25–2:00 | «Производство»: прогноз и календарь смен | Четыре недели спроса/мощности, неделя дефицита, интервалы и ресурс смен |
| 2:00–3:20 | Открыть красный сигнал модерации → «Назначить решение»; проверить проблему, влияние, причину, действие, владельца, срок и приоритет; сохранить | Карточка решения и запись в истории. Для books доступен Михаил, а не владелец другого направления |
| 3:20–4:15 | Взять в работу → описать действие → проверить «Отклонение осталось», затем «Показатель восстановился» | Неудачная проверка оставляет решение открытым; успешная закрывает по измеренному результату |
| 4:15–4:50 | Обновить страницу, открыть решение и журнал | Сохранённые результат, пользователь, время и история проверок |
| 4:50–5:20 | Выйти, войти maxim | Только разрешённое направление photo; прямой запрос другого направления отклоняется сервером |
| 5:20–6:00 | Войти analyst, открыть «Источники данных» и «Финансы и люди» | Свежесть каждого файла, пропуски/дубли, сверка сумм и финансовый план/факт; изменение решений недоступно |

## Короткая проверка ошибки

В новом решении измените действие, нажмите Escape и снова откройте ту же форму: черновик восстановится. При ошибке API он также сохраняется. В «Источниках данных» директор может скачать CSV, удалить обязательный productId и попробовать импорт: ошибка объясняет поле, исходный набор остаётся активным.

Основные действия доступны клавишами Tab/Shift+Tab, Enter/Space; в списках — стрелки, Home/End и Escape. Диалоги закрываются Escape с сохранением изменённого черновика. Кнопка темы переключает светлый/тёмный режим.
