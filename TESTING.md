# Проверки

`npm test` проверяет общий API, CSV-кодек, физические файлы во временном каталоге и D1-совместимое хранилище на SQLite in-memory. Рабочие данные не меняются.

Покрытие: 1 800 заказов / 360 клиентов / 800 обращений и связи; 16 KPI и фильтры; прогноз спроса/ресурса; три уровня ролей и разные данные; отсутствие финансов/файлов у сотрудников; Mary ×3 только у директора; CSV round-trip с UTF-8, кавычками и переносами; импорт и пересчёт; отклонение неверных типов, дубликатов и разорванных связей; сохранение после перезапуска; миграция старых решений; конкурентные записи; неизменность снимка при сбое; идемпотентность; цикл задачи и проверки; восстановление источника; Origin; пагинация Bitrix на подставном REST-ответе.

Дополнительно проверяются рендеры всех разрешённых страниц и деталей для каждой роли с реальными API-данными. `npm run build` собирает Worker со встроенными CSV. Визуальные проверки выполняются отдельно в браузере.

Не проверяются реальные подключения Битрикс24 и SSO: они не настроены. Тесты SQLite/API не заменяют нагрузочное тестирование D1. Локальное Filesystem-хранилище сериализует записи в одном процессе Node; запуск нескольких процессов на одном каталоге не поддерживается.
