# Презентация для сдачи

Актуальный файл: `output/fotoprint-presentation.pptx` — **10 слайдов**, русский язык, 16:9. Текст, таблицы и схема редактируются. Для просмотра нужен PowerPoint, LibreOffice Impress либо совместимый редактор; Node/Java не нужны.

1. Фотопринт — контур управления
2. Пользователи и задача
3. Интегрированные данные
4. Общий дашборд и источники KPI
5. Решение и повторная проверка
6. Архитектура с Metabase и защита
7. Проверки приёмки
8. Единая демонстрация на шесть минут
9. Гипотезы и метрики эффекта
10. Подготовка пилота

Источники и пояснения — в заметках докладчика. Все слайды не читаются подряд в дополнение к демо: использовать введение, приложение и заключение, остальное — резерв вопросов. Экономический эффект и промышленная готовность не заявлены.

Исходник: `build/presentation.mjs`, использует @oai/artifact-tool из bundled Codex runtime. Генератор не нужен для запуска приложения. Для повторного экспорта потребуется установленный runtime и переменная RUNTIME_NODE_MODULES, указывающая на его node_modules; путь к helper/Python в генераторе относится к среде автора. Бинарные зависимости в поставку не включены. Готовый PPTX редактируется независимо от генератора.

Проверка: 10 PNG в `previews-final/`; структурный/геометрический валидатор и повторный импорт прошли. Отчёт для сдачи — `../verification/presentation.json`. Проверка в самом Microsoft PowerPoint не проводилась. Старый восьмислайдовый черновик сохраняется локально, но в итоговый пакет не включается.
