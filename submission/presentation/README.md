# Презентация проекта

Актуальная презентация: `output/fotoprint-presentation.pptx`, 7 слайдов, русский язык, 16:9.

1. Проблема: разрозненные данные тормозят решения.
2. Решение: Фотопринт Контур, общий дашборд и действия.
3. Главное отличие: адаптация к модели данных компании через адаптеры и развитие вместе с ней.
4. Преимущество: источник, формула, фильтры и время каждой метрики.
5. Преимущество: решение завершается проверкой результата.
6. Преимущество: общая система с разными областями доступа.
7. Команда: Владислав Лобацевич, Арсений Зуевский, Марк Скоромец, Тимофей Потапенко; все — 2 курс Мехмат БГУ. Все участники оформлены одинаково.

Для просмотра без PowerPoint открыть `preview.html`: стрелки/пробел, кнопка полного экрана.

Текст и векторные элементы редактируются в PowerPoint. На слайде решения — реальный скриншот демонстрационного продукта; браузерные панели удалены из кадра, значения не изменены. Компания не заявляет реальную выручку или измеренный экономический эффект: показаны демоданные.

Исходник новой версии — `build/redesign.mjs`, итоговые изображения — `previews-redesign/`. Используется bundled @oai/artifact-tool; генератор не нужен для просмотра/редактирования PPTX. Старые версии сохранены в build/history. Архив релиза 3894286 содержит предыдущую презентацию и автоматически не перепубликовывался.
